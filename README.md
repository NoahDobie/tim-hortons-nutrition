# Tim Hortons Nutrition Calculator

A small web app that lets you build a Tim Hortons order and see the combined nutrition for the whole meal — including extras like cream, milk, sugar, and flavoured syrups.

Made by Noah Dobie to help people get a rough idea of what they're eating.

## Disclaimer

This project is **not affiliated with, endorsed by, or sponsored by Tim Hortons** in any way. It was created independently, just to help people out.

Nutrition data is based on publicly available standard formulations from the official Tim Hortons nutrition guide and may not be 100% accurate. Actual values can vary by location, substitution, or how an order is prepared. Always check in-store or on the official Tim Hortons website for the most up-to-date information.

## Features

- Browse the full menu by category and subcategory
- Search across every menu item
- Customize beverages with cream, milk, sugar, and flavoured syrups
- See live, combined nutrition (calories, fat, carbs, protein, sodium, and more)
- Canadian-style Nutrition Facts label with % Daily Value

## Running locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Tech

React + TypeScript + Vite + Tailwind CSS.
